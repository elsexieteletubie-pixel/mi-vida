# mi-vida-
Mi Vida 🌿 es una app web ligera para organizar tu día a día desde el móvil. Gestiona tareas con calendario, controla tus hábitos y rachas diarias, define metas con barras de progreso, lleva el balance de tus ingresos y gastos, y anota ideas al instante. Todo de forma local, rápida y con modo oscuro automático. ✨
